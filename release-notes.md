## 0.1.0 (2026-11-14)


###   BREAKING CHANGES

* the integration task scope and callbacks drop `pullRequest` for `pullRequests`; the run review answers `landings`; the migrations are collapsed into a new initial_schema, so a database on the old ledger must be reset.
* the task API returns pullRequests instead of pullRequest, task decisions return merges instead of merge, and the checks tool answers { pullRequests: [...] }.
* fix the strict-DDD audit, and split Lines and Runs out of Work ([#531](https://github.com/usespotlightai/spotlight/issues/531))
* call any OpenAI-compatible model endpoint instead of OpenRouter ([#526](https://github.com/usespotlightai/spotlight/issues/526))
* each event in `on` takes a list of bindings instead of one.
* the editor socket takes a lease instead of ?task= or ?chat=; a CLI older than this change cannot open a sandbox.
* split the OpenAPI spec per audience and move the resource API to /api/v1 ([#454](https://github.com/usespotlightai/spotlight/issues/454))
* Run a task's next run in its live sandbox instead of a warm wait
* Rename token trusts to OIDC trusts, and show them beside tokens on one API access page ([#352](https://github.com/usespotlightai/spotlight/issues/352))
